# Herdr's rewrite opens a window for Clotho

Clotho has one direct architectural twin, herdr, and a crowded field of partial substitutes. That leaves Clotho without a unique feature but with a unique combination. Herdr is an Apache-2.0 Rust daemon with workspace-like "spaces", tabs, panes, SSH multi-machine and an agent sidebar. It has **~46.9k GitHub stars, a $6M Bessemer-led seed and YC F26 backing** ([GitHub](https://github.com/herdrdev/herdr); [Herdr blog](https://herdr.dev/blog/herdr-raised-a-seed/)). It is the most dangerous competitor, but its brand-new desktop app (launched 2026-10-30) gave up two things Clotho does well. It only shows status for agents that emit its OSC 7501 protocol, and after a reboot it brings panes back as fresh shells rather than resumed agents ([herdr-app](https://github.com/herdrdev/herdr-app); [herdr-core](https://github.com/herdrdev/herdr-core)). The second threat is the platform vendors. **Anthropic's Claude Code Remote Control (Feb 2026) and Codex in the ChatGPT app (May 2026)** now give single-vendor users free push notifications, phone approvals and diffs ([Claude Code docs](https://code.claude.com/docs/en/remote-control); [MacRumors](https://www.macrumors.com/2026/05/15/openai-brings-codex-chatgpt-mobile-app/)). Meanwhile, between July and October 2026, nearly every worktree orchestrator (Conductor, Paradev, Orca, cmux, Nimbalyst, Orchestrator.inc) shipped an iPhone companion. A phone app plus push is now table stakes, not a moat. Clotho's defensible position combines four things no competitor ships together: a single daemon that owns live PTYs (no tmux), exact Claude/Codex conversation restore after a reboot, first-party native Mac *and* iPhone clients over plain SSH with no vendor relay, and pane-anchored agent state with lock-screen approvals. The biggest gaps are worktree-per-pane with a diff view, agent breadth beyond Claude and Codex, and zero-config pairing. The pricing evidence points to a free daemon and Mac app, with a **~$8–10/month (or ~$80–100/year) Pro tier** on the iPhone power features.

## Herdr built Clotho's architecture first, then stepped back on two points

Herdr matters most because its design is nearly the same as Clotho's. Solo developer Can Celik started it in March 2026. In its own words, it is a background server that "keeps terminals running… when you close the client or lose your SSH connection" ([herdr README](https://github.com/herdrdev/herdr)). Version 0.9 (2026-09-07) added "several machines, one window" over SSH, with a combined agent list ([Connecting the machines](https://herdr.dev/blog/connecting-the-machines/)). Live updates replace the server while pane processes keep running, which is the same in-place upgrade Clotho uses ([herdr blog](https://herdr.dev/blog/)). The new desktop app uses a **space › tab › pane** model, an agents sidebar (Working/Blocked/Done/Idle) and a Cmd+Shift+P command palette ([herdr-app](https://github.com/herdrdev/herdr-app)). The headless core even has CLI file transfer: `hc put box/build ./report.txt` sends a file next to a remote terminal ([herdr-core machines.md](https://github.com/herdrdev/herdr-core/blob/main/docs/machines.md)). Almost every Clotho feature bullet has a herdr counterpart.

Its traction is real and fast. Herdr went from launch to **25k stars and 340k downloads by August** ([YC post](https://herdr.dev/blog/herdr-is-joining-y-combinator/)) and 46.9k stars by October. It has four HN threads above 160 points (404, 318, 281, 166), stable releases every one to two weeks, and a plugin marketplace with **500+ plugins a month after launch** ([HN 48756578](https://news.ycombinator.com/item?id=48756578); [herdr releases](https://github.com/herdrdev/herdr/releases)). Herdr is ahead of Clotho on Windows support, on breadth (about 20 agents with integrations), on an agent-to-agent orchestration API (`hc run --bg`, `hc send`, `hc wait --children all`), on a published OpenRPC client schema, and on JavaScript "mods" for layouts and panels ([herdr docs: agents](https://herdr.dev/docs/agents/); [herdr-core](https://github.com/herdrdev/herdr-core)). Everything is free and Apache-2.0. The only monetization signal is a planned "Herdr Cloud" relay that would connect machines "with one command" and remove SSH setup ([Connecting the machines](https://herdr.dev/blog/connecting-the-machines/)).

**Herdr has no official mobile app.** That gap is filled by a fragmented third-party ecosystem. The strongest piece is **Heeler** (703★): a native iOS console with a libghostty terminal, QR pairing, push "when an agent needs you", a Live Activity on the lock screen and a git Changes view, available on the App Store ([Heeler](https://github.com/ZingerLittleBee/Heeler)). Around it sit herdrup (iOS/iPad/Mac, 230★), an Android "herdr mobile" with hold-to-confirm risky answers, a PWA relay (333★) that offers "approve and monitor Herdr agents remotely from your phone", and Shepherdr, a tailnet-only mobile web UI ([herdrup](https://github.com/jerryfane/herdrup); [herdr-mobile](https://github.com/tuan3w/herdr-mobile); [herdr-mobile-relay](https://github.com/0cv/herdr-mobile-relay); [Shepherdr](https://github.com/luiscleto/shepherdr)). On launch day an HN commenter was disappointed that the "native app" was not a mobile app ([HN 50298436](https://news.ycombinator.com/item?id=50298436)). That shows unmet demand, and it is the obvious next step for a funded team.

The October rewrite created an opening. The new core "does not guess from screen text or recognize agent brands. A program that does not report status has none" ([herdr-core](https://github.com/herdrdev/herdr-core)). On launch day a user reported that "it doesn't pick up Claude Code agents. My Agents pane stays empty" ([HN 50298436](https://news.ycombinator.com/item?id=50298436)). The app's README also says that after a reboot, "kept panes get fresh shells in their last folders, not their old programs" ([herdr-app](https://github.com/herdrdev/herdr-app)). The older TUI could resume supported agent sessions through integrations, but the TUI "doesn't share agents with the app" ([herdr.dev](https://herdr.dev)). For now, then, herdr's flagship product does worse than Clotho on the two things Claude Code and Codex users feel daily: knowing which agent needs you, and getting the conversation back after a restart. Herdr ships every week or two, so this window could close within weeks. Other open complaints include telemetry on by default, selection bugs on macOS, Vulkan required on Linux, and VC "enshittification" worries with references to Warp ([herdr-app](https://github.com/herdrdev/herdr-app); [HN 49201003](https://news.ycombinator.com/item?id=49201003)).

## Vendors and free companions made phone approvals a commodity in 2026

Two 2026 launches remove "control Claude from your phone" as a selling point on its own. **Claude Code Remote Control** connects the Claude iOS/Android apps and web to a session on your machine. It has push for "actions required", permission prompts that stay open until answered, a git diff pane, and a server mode with up to 32 concurrent sessions that can be started from the phone ([Claude Code docs](https://code.claude.com/docs/en/remote-control)). **Codex in ChatGPT** (preview 2026-05-14) does the same for Codex on a Mac: notifications, command approvals, new threads and diffs, with "files, credentials, and permissions stay[ing] on the machine" ([MacRumors](https://www.macrumors.com/2026/05/15/openai-brings-codex-chatgpt-mobile-app/)). Both come at no extra cost with subscriptions users already pay for.

The vendor features are still single-agent, chat-shaped and relayed through the vendor. The structural limits are documented. Remote Control stores the transcript on Anthropic servers while connected. It is unavailable with API keys, Bedrock, Vertex, Foundry, custom base URLs, gateways, and ZDR or HIPAA orgs. `!` shell mode doesn't run from mobile. When the process exits the session goes offline, and the docs tell remote users to run it inside `tmux`/`screen` ([Claude Code docs](https://code.claude.com/docs/en/remote-control)). There are also open reports of its pushes not reaching linked iPhones ([claude-code#28765](https://github.com/anthropics/claude-code/issues/28765)). Each of these is something Clotho sells: a real persistent PTY, Claude and Codex in one list, and no vendor relay. The cloud-sandbox agents (Claude Code on the web, Copilot coding agent, Cursor Cloud Agents, Jules) answer a different job, "delegate a task that ends in a PR", and overlap less ([GitHub Docs](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-on-mobile); [Cursor blog](https://cursor.com/blog/agent-web)).

The independent companions split into two groups. **Paseo** (22.5k★, Apache-2.0) is Clotho's closest architectural analog outside herdr. It is "a local server called the daemon that manages your coding agents" with Electron desktop, iOS, Android, web and CLI clients, split-pane terminals, worktrees, multiple machines, seven-plus agents, an optional E2E relay and "no telemetry" ([Paseo](https://github.com/getpaseo/paseo)). **Happy** (24.4k★, MIT) wraps the `claude`/`codex` CLIs, adds an E2E-encrypted relay (self-hostable, with a Cloudflare Worker push server) and supports multiplayer steering. Its pitch is "Happy adds a harness, not another bill" ([Happy](https://github.com/slopus/happy)). A competitor reports that taking control from the phone restarts Happy's session in remote mode, so it is not a persistent terminal ([Agentastic](https://www.agentastic.dev/compare/claude-code-iphone)). On the terminal side, **Moshi** is the closest single-app rival to Clotho's iPhone app. It is an SSH/mosh terminal "built for agent sessions" with tmux *and herdr* auto-attach, an inbox with approve/deny/answer actions, push, Live Activities and Apple Watch support. It has a metered free tier and Pro from $9.99/month ([Moshi docs](https://getmoshi.app/docs/subscription)). The cautionary tale is **Omnara**. This YC-backed "command center to monitor… your agent—right from your phone" labeled its remote-coding product "historical" in January 2026 and pivoted to a managed-agent platform ([RuntimeWire](https://runtimewire.com/article/startup-spotlight-omnara-agent-control-plane)). The timing suggests, but does not prove, that a stand-alone paid phone remote was squeezed once the vendors shipped theirs.

One finding in the research notes needs correcting. Live Activities are **not** unique to Clotho: Heeler ships a lock-screen Live Activity and Moshi meters "agent-event push… shared with Live Activities" ([Heeler](https://github.com/ZingerLittleBee/Heeler); [Moshi docs](https://getmoshi.app/docs/subscription)). Actionable Allow/Deny buttons on the lock-screen notification itself are rarer. The research confirmed them only in DIY hook projects such as claude-push ([claude-push](https://github.com/coa00/claude-push)), and it found no evidence either way for the Claude or ChatGPT apps. Clotho should treat this as a polish lead, not a moat.

## Worktree orchestrators all shipped iPhone apps between July and October

The third category is the desktop "agentic development environment". It has settled on one pattern: **one git worktree and branch per task, a status sidebar, a diff/PR review pane**, and since mid-2026, remote hosts plus an iPhone app. Conductor shipped "Conductor for iOS" on 2026-10-02 and Mac remote control on 2026-10-23 ([Conductor changelog](https://www.conductor.build/changelog)). Paradev (renamed from Superset in October) puts remote hosts, its iOS app and automations behind **Pro at $20/user/month**. It also advertises "persistent sessions that survive restarts" ([Paradev](https://github.com/ParadevAI/Paradev); [Paradev compare](https://paradev.com/compare/superset-vs-orca)). Orca (MIT) fans one prompt out to several agents, "merge[s] the winner", and has iOS and Android companions ([Orca](https://github.com/stablyai/orca)). Its reported 110.9k stars against 148 watchers is anomalous and should not be read as real adoption. Orchestrator.inc runs a kanban with a literal **"Needs you" lane** and sends mobile push "when an agent has a question or needs approval" ([Orchestrator.inc](https://github.com/OrchestratorInc/agent-orchestrator)).

**cmux is the most philosophically similar tool.** It is a native Ghostty-based Mac terminal (not Electron) that works with any agent. It shows attention rings on panes, a notifications panel, and a sidebar with git branch, linked PR status, cwd and listening ports. It also has `cmux ssh` remote workspaces and an iOS TestFlight beta ([cmux](https://github.com/manaflow-ai/cmux)). That covers Clotho's branch/PR-per-pane and "needs attention" features. cmux's weak spot is persistence. It saves layout, cwd and best-effort scrollback but "does not keep live processes", and it sends users to `cmux local-tmux` or ssh-tmux for real detach and reattach. Clotho's daemon is the clean answer to that.

The category is also unstable. Vibe Kanban (28.5k★) shut down in April 2026, Terragon in January, and Crystal folded into Nimbalyst ([Vibe Kanban shutdown](https://vibekanban.com/blog/shutdown); [terragon-oss](https://github.com/terragon-labs/terragon-oss); [Crystal](https://github.com/stravu/crystal)). Cloud-hosted orchestration has been the riskiest model, and local-first tools have survived. That supports Clotho's no-vendor-cloud design. The incumbents form the floor below all of this. tmux and Zellij keep sessions through detach but lose processes on reboot (Zellij resurrection re-creates layout and commands, and tmux-resurrect hasn't been updated since 2024-08). Wave's durable sessions are opt-in and SSH-only. Mosh and ET only fix the network ([Zellij docs](https://zellij.dev/documentation/session-resurrection); [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect); [Wave docs](https://docs.waveterm.dev/durable-sessions)). The common DIY stack is tmux plus Tailscale plus Blink or Termius plus a hook-to-ntfy script. It takes four to six pieces and approvals are handled as tmux keystrokes, which shows both the demand and the friction ([tap-to-tmux](https://github.com/flavio87/tap-to-tmux); [claude-pager](https://github.com/FilipCondac/claude-pager)).

## Ranking the threats: Anthropic's reach, herdr's momentum, Paseo's breadth

| Rank | Threat | Why it hurts | Clotho's counter |
|---|---|---|---|
| 1 | **Claude Code Remote Control** (and Codex in ChatGPT) | Free, zero-setup and already on users' phones; "good enough" for single-vendor, single-machine users | Real PTY, multi-vendor, multi-machine, no transcript relay, works for API-key/Bedrock/ZDR users |
| 2 | **herdr** | Same architecture, 47k★, funding, weekly releases, Windows, ecosystem; a first-party mobile app or Herdr Cloud would hit Clotho head-on | Out-of-the-box Claude/Codex status and exact restore today; first-party iPhone app; native Apple polish |
| 3 | **Paseo** | Free daemon plus native mobile on iOS, Android and web; multi-agent; no telemetry | Native Swift instead of Electron/Expo; live PTYs through upgrades and reboots; lock-screen approvals |
| 4 | **cmux / Paradev** | Native terminal with branch/PR and attention (cmux); worktrees, diff review and remote hosts (Paradev) | Own daemon instead of tmux; no paywall on remote hosts or iOS |
| 5 | **Moshi** (with Heeler) | Agent-aware iPhone terminal with inbox, Live Activities and Watch, on top of tmux or herdr | Clotho's iPhone app shares one model with a Mac app and daemon; no tmux glue |

Remote Control ranks first because distribution beats features. Most Claude Code users will never look past the button already in their app. Herdr ranks second only because it is still missing a first-party mobile client and reliable Claude status, and both are fixable. **The worst case is herdr shipping an official iPhone app plus Herdr Cloud pairing.** That would match Clotho's whole pitch for free with a 47k-star community. Nothing has been announced, but the ecosystem demand makes it likely.

## Clotho's moat is the combination, and five gaps need closing

Looked at one by one, almost every Clotho feature exists somewhere else: persistence (herdr, Paseo), multi-machine SSH (herdr, cmux, Paradev Pro), "Needs you" (Orchestrator.inc, Heeler), phone approvals (vendors, Happy, Moshi), Live Activities (Heeler, Moshi), branch/PR per pane (cmux), a command palette or quick open (herdr-app, Orca), and file transfer (herdr's `hc put`). What no competitor documents is the full set together. Clotho's set is a single daemon that owns live PTYs and survives client loss, in-place upgrades and reboots, with the **exact Claude/Codex conversation resumed per pane**. On top of it sit **first-party native Mac and iPhone clients** rendering the same Workspaces/Tabs/Panes. The machines connect **over plain SSH with no vendor cloud or paid tier**. And agent state is anchored to panes, so a lock-screen Allow goes to the right agent. The sharpest marketing contrasts are "Remote Control's docs tell you to use tmux; Clotho is what you'd use instead", "herdr's app gives you fresh shells after a reboot; Clotho gives you your conversation back", and "Paradev and Conductor charge for remote hosts and iOS; Clotho's are yours." The brief's claim of surviving reboots should always be worded precisely. Processes cannot survive a reboot, so the claim is that layout and agent conversations are restored. Otherwise a reviewer will compare it to Zellij resurrection and call it parity.

The gaps, in priority order:

**First, worktree-per-pane and a per-pane diff view.** Eleven tools treat a fresh worktree and branch per task as the default, and Conductor, Paradev, Vibe Kanban and Emdash all review diffs in the app ([Paradev](https://github.com/ParadevAI/Paradev); [Conductor changelog](https://www.conductor.build/changelog)). Clotho already shows branch/PR per pane, so "new pane in a fresh worktree" plus a read-only changes view on Mac and iPhone closes the most visible gap without abandoning the terminal-first model. **Second, agent breadth and generic status.** Herdr recognizes about 20 agents and Emdash claims 30+ ([herdr docs](https://herdr.dev/docs/agents/); [Emdash](https://github.com/generalaction/emdash)). Clotho should add hooks for the next tier of agents (OpenCode, Gemini/Antigravity, Copilot CLI, Pi). It should also accept the generic escape-sequence protocols (OSC 9/99/777 as cmux does, and herdr's OSC 7501), so any program can mark a pane as needing you. That turns herdr's protocol bet into Clotho compatibility. **Third, zero-config pairing.** Remote Control, Codex, Happy and Heeler all pair by QR code, and Herdr Cloud promises one-command machine linking. Clotho can keep its no-cloud principle and still offer QR pairing that sets up the SSH key and finds the host over Tailscale.

**Fourth, a scriptable surface.** This means a published protocol schema, a CLI or MCP tool that lets agents spawn panes, send input and wait on other panes, and an agent "skill" file. Herdr's `hc` and Paradev's SDK and MCP server show that agents increasingly drive the multiplexer themselves ([herdr-core](https://github.com/herdrdev/herdr-core); [Paradev](https://github.com/ParadevAI/Paradev)). **Fifth, a minimal non-Apple client.** A small web view of the "Needs you" list with approve/deny would cover Android and Windows users on teams where one person uses an iPhone. Everyone else in the companion space (Happy, Paseo, the vendors) reaches Android. The research does not support chasing kanban boards, issue-tracker intake, an in-app browser, scheduled automations, prompt fan-out or a Windows daemon now. Those are orchestrator features, and the category that pioneered them is where the shutdowns happened.

## Free core, paid iPhone power features at about $8–10 a month

Clotho is pricing against three anchors: free open-source rivals with 20k–47k stars (herdr, Paseo, Happy, cmux), vendor features bundled into subscriptions users already have, and a narrow band of what individual developers pay for native tools. That band is **$9.99/year** for Prompt 3 across four Apple platforms, **$15–20/year** for Blink, ShellFish or La Terminal, **$8–10/month** for Raycast Pro, Termius Pro or Moshi Pro, and **$20/month** only when AI usage or team features come bundled (Warp Build, Paradev Pro) ([Panic FAQ](https://help.panic.com/prompt/purchase-faq/); [La Terminal](https://apps.apple.com/us/app/la-terminal-ssh-client/id1629902861); [Termius pricing](https://termius.com/pricing); [Moshi docs](https://getmoshi.app/docs/subscription); [Warp pricing](https://www.warp.dev/pricing); [Paradev compare](https://paradev.com/compare/superset-vs-orca)). A paid daemon cannot compete with herdr and Paseo. Gating multi-machine would invite the obvious "herdr does it free" comparison.

The recommended shape is a **free clothod and free Mac app with unlimited machines**. The iPhone app gets a free tier with metered push, the way Moshi meters 10 events a minute and 5 inbox actions. **Clotho Pro at about $8–10/month or $80–100/year** would unlock unlimited push and approvals, lock-screen Allow/Deny, Live Activities, file transfer to and from the phone, and later Watch support. A **~$99 lifetime option** fits the iOS norm ([La Terminal](https://apps.apple.com/us/app/la-terminal-ssh-client/id1629902861); [ShellFish](https://apps.apple.com/us/app/secure-shellfish-ssh-sftp/id1336634154?uo=4)). Metering push is not arbitrary: the APNs relay is the one running cost Clotho carries, and charging for it matches value to cost. A team tier (shared machines, "Needs you" fan-out to several people) can wait until there is demand. One open question the research cannot settle is source availability. Every high-traction rival is open source or source-available, and HN readers punish closed developer tools and telemetry alike. Publishing clothod under a permissive or source-available license while keeping the apps proprietary would neutralize herdr's openness argument at little cost. Whether that helps the business depends on distribution goals the research did not cover.

## Conclusion

The market has already settled the question of whether developers want to steer agents from their phones: herdr's third-party mobile ecosystem, two first-party vendor launches and six orchestrator iPhone apps in four months all say yes. What it has not settled is who owns the *session*, the live terminal, its agent conversation and its machine, across devices and reboots. The vendors don't, because they push users to tmux. The orchestrators mostly don't, because they restore layout or rely on tmux. Herdr's new app just stopped doing it for agent conversations. That is the ground Clotho should claim. The work is narrow: make reboot-restore and out-of-the-box Claude/Codex status visibly better than herdr's, add worktree panes with a diff view, pair with a QR code, and price the iPhone as the premium surface rather than the daemon.

The main uncertainty is speed. Herdr ships weekly with funding behind it, and an official herdr iPhone app or a working Herdr Cloud would erase Clotho's clearest lead. Clotho's advantage is real today but perishable, so the priority is getting the iPhone app out of TestFlight and in front of herdr's frustrated Claude Code users while their Agents pane is still empty. Several inputs need checking before high-stakes decisions: Orca's star count, Conductor's funding, whether Paseo or Paradev restore agent conversations after a reboot, and whether the Claude and ChatGPT apps offer lock-screen action buttons. The comparison pages from Nimbalyst and Agentastic are written by competitors.
