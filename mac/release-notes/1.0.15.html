Clotho 1.0.15

  • Clean notifications. Agent notifications no longer show raw Markdown: no stray asterisks, backticks or link syntax, and lists read as “•” items.
  • One clear line from Claude Haiku. With clothod 0.1.29, each notification says in a sentence what the agent did or needs. The Agents panel shows the same line. A permission request still names the exact tool and command you're allowing.
