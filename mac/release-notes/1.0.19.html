Clotho 1.0.19

  • The sidebar opens with your agents. Needs you, Done and Working sit on top of the workspaces, one line each. The separate Agents panel is gone.
  • The same state mark shows on workspaces, on tabs and in a new header on every pane.
  • Answer a permission request in its pane. The request shows there with Deny and Allow; ⌘↩ allows and ⌘. denies. They turn on half a second after the request appears, so a double tap can't approve the next one unread.
  • ⌘P shows each agent's state and branch, filters by “needs”, “working” or “done”, and ⌥↩ allows a request.
