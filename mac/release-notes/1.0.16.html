Clotho 1.0.16

  • A file sidebar. Click the sidebar button at the top right, or press ⌥⌘B, to see the files of the folder you're in, on whichever machine the pane is on. It follows you as you cd or switch panes. Browse somewhere else and “Follow Pane” takes you back.
  • Double-click to open a file from another machine. It opens in its usual app on your Mac, and every save goes straight back to the machine. If someone changed the file there in the meantime, Clotho asks before overwriting it: keep yours, save yours as a copy beside it, or take theirs.
  • Each file you've opened shows whether it's open, saving or saved. Right-click for Open With, Download To, Copy to another machine, Rename and Delete. Drag files from Finder onto the sidebar to upload them.
