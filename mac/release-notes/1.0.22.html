Clotho 1.0.22

  • Any program can now ask for you. A script's clothod report --state waiting --message "…", or a terminal notification, shows under Needs you and on your phone.
  • Gemini CLI, OpenCode, GitHub Copilot CLI, Aider, Amp and Cursor Agent show by name.
  • Progress from tools that report it shows on the tab and the agent's row.
  • Agent Status (the machine's menu and Settings › Machines) sets up each agent's hooks one by one, now also for Gemini CLI and GitHub Copilot CLI.
  • Changes updates when files change instead of every few seconds.
  • Needs clothod 0.1.33 on each machine; Clotho offers the update.
