Clotho 1.0.9

  • Switch a machine off. Manage Machines has a switch for each machine. Off disconnects it right away and hides it from the sidebar, Agents and ⌘P. Its shells keep running there, and switching it back on brings them back.
  • Sort files by any column. Click Name, Size, Modified or Kind to sort, and click again to reverse. Folders stay on top, and each side remembers its order.
  • Filter files. Type in a side's filter field, or press ⌘F, to show only the names that match.
  • Copy between any two machines. Either side of the file browser can be any machine, so you can copy straight from one remote machine to another. The copy goes through your Mac, with progress and Cancel.
