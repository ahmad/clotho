Clotho 1.0.20

  • The right sidebar is now an inspector with three views: Changes, Files and Activity. ⌥⌘B shows or hides it.
  • Changes lists what the focused pane's agent changed: uncommitted work first, then the branch against its base, each file with its diff. Press Return on a file for a side-by-side diff.
  • The strip at the bottom of a pane and ⌘P show the lines and files changed.
  • New Tab in a Worktree (File menu and ⌘P) makes a fresh worktree and branch beside the repository and opens a tab in it.
  • Needs clothod 0.1.32 and git 2.31 or later on each machine; Clotho offers the clothod update.
