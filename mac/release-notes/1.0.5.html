Clotho 1.0.5

  • Git at a glance. Each tab shows its branch and pull request; the sidebar shows each workspace's branch; the focused pane has a thin strip with the repo, branch, worktree and PR (click it to open on GitHub); and ⌘P finds tabs by branch, worktree or PR number. Pull requests need GitHub's gh, signed in. Comes with clothod 0.1.23.
